## 1. 唯一識別碼與狀態定義

### 1.1 實體 ID

- **Source-ID（SRC）：** 一個可引用的頁面／報導／影像候選。若兩個網站轉載同一媒體內容，保留不同頁面 URL，但在「來源依賴」欄指向同一上游來源。
- **Evidence-ID（EVD）：** 可支持或反駁特定主張的具體報導段落、引述或影像可見資訊。它只記錄該來源實際呈現的內容，不代表內容已經由原始卷宗驗證。
- **Claim-ID（CLM）：** 能獨立判真假的原子主張。一列只處理一個命題。
- **Event-ID（EVT）：** 一個時間／行為事件。事件發生時間與報導／通知時間分開。
- **Location-ID（LOC）：** 一個地名或位置候選。原始名稱、標準化名稱與事件類型分開保存；同一地名不保證是同一事件。
- **Hypothesis-ID（HYP）：** 可由材料支持、反對或加以區分的解釋，不等同事實。
- **Action-ID（ACT）：** 一項原件取得、來源追溯或測試行動，須指定可改變的 Claim-ID 與完成條件。

### 1.2 主張狀態

| 狀態 | 意義 | 使用規則 |
|---|---|---|
| REPORTED_CONVERGENT | 多個公開報導的基本敘述一致，但尚未核對原始案卷 | 只可寫「公開報導記載」；不能自動升級為一手事實 |
| CONFLICTED | 存在兩個以上未能裁決的來源版本 | 不以多數決或故事合理性決定 |
| DISPUTED | 地點、日期或陳述存在直接爭議，但不同來源可能談的是不同事件語義 | 先拆事件定義，再尋找原始依據 |
| REPORTED_SINGLE_SOURCE | 只有一個可辨識來源鏈支持 | 保留來源限制，不作確定性擴大 |
| RUMOR_REPORTED_NOT_CORROBORATED | 媒體證實「傳聞存在」，未證實傳聞所指案件事實 | 不把傳聞存在等於傳聞為真 |
| CONTRADICTED_AT_PUBLIC_REPORT_LEVEL | 可追溯報導記錄了當時警方／相關方對傳聞的反向答覆 | 只裁決該傳聞所聲稱的狀態，不延伸到其他未知事實 |
| NOT_VERIFIED | 目前找不到足以確認該主張的來源 | 「未找到」不是「不存在」 |
| BLOCKED_BY_PRIMARY_SOURCE_ACCESS | 關鍵裁定需要原始文件／正式資料，本研究未取得 | 保留待查，不用推理填空 |
| NOT_TESTABLE_FROM_PUBLIC_DATA | 目前公開材料不足以測試該主張或估算個人涉案可能性 | 除非新資料改變，不繼續推演 |
| HISTORICAL_STATUS_ONLY | 來源僅能證明過去某日的情況 | 不延伸成當前狀態 |

4. **2021 年懸賞通告影像／文字：** 新浪所刊華商報報導稱記者獲得通告；現存第三方圖像候選尚未證明與該圖同源或為完整原件。兩者先記錄為可能關聯，不能直接合併或認定同一物件。
5. **2019 年深圳落網傳聞：** 南方日報／南方+與新京報同期報導都記錄同一傳聞及警方回應；可作當時多家新聞機構查問的佐證，但被詢問的警務機關答覆是共同的核心上游，不把轉載文章重複算作獨立「案件線索」。
6. **2022 年江姓醫師傳聞：** 澎湃新聞是本輪找到的主要報導；北京日報、新浪等刊載相同或近乎相同文字，全部連回同一 Source root（SRC-009），不得多次計票。
7. **網路匿名論壇與 2022 年彙整文章：** 原始帖子、化名作者和後續彙整文不是獨立官方來源。若原帖明示虛構／不可當真，不能因後來文章省略警告就升級證據。
8. **第三方舊報紙圖片：** 頁面預覽、圖片路徑、後續對圖片的文字轉述都可能來自同一圖片，不等於已取得館藏原件。

### 6.2 去重規則

- 每一個報導頁面保留 URL，Source-ID 的 lineage 欄記錄上游來源；獨立性不按域名數量判定。
- 若多篇文章使用同一報導／同一受訪者說法，該內容只算一個來源根；後續文章若新增加直接查證或原件，才記成新的 Evidence-ID。
- 媒體轉述官方說法，應表明「媒體記錄某官方人員當時如此表示」，而不是標作「本研究直接取得官方卷宗」。
- 匿名來源的內容即便具體，也不因細節豐富而提高可信度。
- 官方否認某次抓獲傳聞只能降低該項傳聞的證據地位；不證明所有其他未知案情，也不等於本研究能判定被傳聞個人的全部情況。

4. **實際行為人、動機、職業、工具、行為人數：** 目前公開材料不足，不能靠案件手法或點位推導出確定身份。

6. **當前官方案件狀態：** 本輪未能核實 2026 年最新官方通報；只保留明確日期的歷史狀態。

## 10. 最終裁定

本輪完成的是**共同主張—來源—證據台帳第一版**，讓最重要的公開案件主張開始具備唯一 ID、來源鏈、可支持範圍、反證與下一步動作。這使後續資料新增能定位受影響結論，也可減少把同源轉載誤當多份獨立證據的風險。

本輪沒有解決案件真相，沒有確認任何私人個體涉案，也沒有完成原始館藏核驗或系統 Runtime 驗收。所有高影響未知保留明確狀態；後續只有在新資料具有可追溯來源並能改變相應 Claim-ID 的狀態時，才更新推理結論。
