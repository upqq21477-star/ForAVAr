## 0. 藍圖總結

本案的分析目標不是無限收集文章或把已知報導串成流暢故事，而是建立可被新增證據修正的事件模型，並回答哪些線索能協助識別或排除行為人。

本藍圖把層級固定為：

- **核心 C0：** 找出行為人；若證據不足，正確結果可以是縮小範圍、排除部分模型，或保留未能確定。
- **主軸 P01–P10：** 核心延伸出的十個不可互相取代的大方向。
- **骨架 Bxx：** 每條主軸向下分出的分析責任節點。每條主軸目前配置四個骨架，符合本專案採用的「每條主軸至少對應三個有區別的骨架」結構檢查規則。
- **框架 Fxx：** 每個骨架一對一對應一個框架模組；框架可再分成工作步驟、欄位、檢驗和子任務，不把細項提前提升為主軸。
- **驗收：** 不以文件數量、篇幅、搜尋次數或敘事完整度代替可觀察的問題進展。

「每主軸至少三個骨架」是本專案的結構驗收規則，不是聲稱犯罪學或所有分類系統都存在的普遍定律。骨架少於三個時，應先檢查主軸是否過度細分、與其他主軸重疊，或目前範圍定義不足；不為了湊數而製造空泛分支。

## 1. 核心與十條主軸

### C0｜找出行為人

用可驗證事實、犯罪行為重建、人物關係、動機與能力假說、時空條件及證據比較，識別或排除候選解釋。核心是目標，不是先假定一定能得到唯一答案。

| 主軸 | 方向 | 必須回答的問題 |
|---|---|---|
| P01 | 被害者與受害者背景 | 為什麼被害者的背景、生活及接觸範圍與案件有關？ |
| P02 | 行為人特徵、能力與限制 | 已知行為對能力、資源、技能及限制提出哪些最低要求？ |
| P03 | 犯罪行為與作案手法 | 有哪些行為可以重建，事件各階段的先後如何？ |
| P04 | 人物關係、接觸與交集 | 哪些人或群體具有可驗證的關係、接觸或接近機會？ |
| P05 | 犯罪動機與行為目的 | 哪些目的假說可以解釋犯罪與犯後行為？ |
| P06 | 環境、空間與作案機會 | 場所、動線及環境條件限制或支持哪些事件模型？ |
| P07 | 時間與事件順序 | 不同時間欄位、事件先後與可行時間窗口如何界定？ |
| P08 | 證據、來源與事實驗證 | 什麼是事實、來源所述、推論、假說或未知？證據是否獨立？ |
| P09 | 跨案件關聯與行為模式 | 是否存在有區辨力、可獨立驗證的跨案關聯？ |
| P10 | 候選對象識別、比較與排除 | 如何建立候選假說、比對證據、處理反證及排除錯誤對象？ |

主軸邊界：
- P02 推估行為所需的能力與限制；P10 比較實際候選對象。符合某種特徵不等於涉案。
- P03 重建發生了什麼；P05 分析可能為何發生。動機不能代替行為證據。
- P04 管理關係與接觸線索；P05 管理這些線索能否支持動機。認識被害者不代表有犯罪動機。
- P06 分析空間可能性；P07 分析時間可能性。地理相鄰不等於事件順序，發現時間不等於實際放置時間。
- P08 負責證據品質及推論門檻，為全部主軸提供校正，不等同一般性的資料整理。

## 2. 骨架—框架一對一對應表

每個框架模組使用同一個基本契約：**輸入 → 處理 → 輸出 → 驗收 → 未解／回退條件**。下表先定義各模組的唯一主要責任；框架內部可再向下拆分。

### P01｜被害者與受害者背景

| 骨架 | 一對一框架 | 主要工作與輸出 |
|---|---|---|
| B01.1 身分與基本背景 | F01.1 被害者基礎檔案 | 整理可確認的身分、生活、學習／工作背景；輸出來源可追溯的基本資料表。 |
| B01.2 日常生活與活動模式 | F01.2 生活基線模型 | 建立有來源支持的日常活動範圍與慣常模式；區分一般模式與例外。 |
| B01.3 事件前活動及接觸 | F01.3 事件前活動重建 | 整理最後確認活動、直接接觸與時間錨點；不把傳聞補成行蹤。 |
| B01.4 被害者選擇與風險背景 | F01.4 被害者選擇分析 | 比較針對性、關係性、機會性等假說，並列出區辨性證據。 |

### P02｜行為人特徵、能力與限制

| 骨架 | 一對一框架 | 主要工作與輸出 |
|---|---|---|
| B02.1 技能與知識需求 | F02.1 能力需求分析 | 從已確認行為推估最低必要技能，列出非職業性替代來源。 |
| B02.2 工具、資源與取得條件 | F02.2 資源條件模型 | 檢查工具／資源的特定性、取得門檻及多種替代來源。 |
| B02.3 規劃、熟練與應變 | F02.3 行為能力分析 | 區分有證據的預先規劃、操作熟練度及臨場反應，不以結果反推專家身分。 |
| B02.4 身體條件與個人限制 | F02.4 行為人限制模型 | 只在行為或可靠資料提供依據時，評估身體條件、時間、資源等限制。 |

職業推算規則：先建立「行為 → 必要技能 → 可能取得途徑 → 候選職業群 → 區辨證據」的推論鏈。沒有職業專屬性或獨立證據時，只能標記為待比較假說，不能認定職業、人格或身分。

### P03｜犯罪行為與作案手法

| 骨架 | 一對一框架 | 主要工作與輸出 |
|---|---|---|
| B03.1 犯前、犯中、犯後序列 | F03.1 行為序列模型 | 把事件拆成階段與可觀察行為，標示順序確定度與未知區間。 |
| B03.2 接近、互動及犯罪發生 | F03.2 犯罪行為重建 | 根據物證、證言與可核驗紀錄，建立可能行為順序及替代版本。 |
| B03.3 犯後處置與現場變化 | F03.3 犯後處置分析 | 檢查是否確有處置、隱匿或現場變動；不預設行為目的。 |
| B03.4 作案手法、個人化行為與布置 | F03.4 行為分類鑑別 | 區分完成犯罪所需的作案手法、可能的個人化行為、現場布置與其他解釋。 |

本主軸輸出是「做了什麼、何者可證、順序如何、還缺什麼」，不是單憑描述性詞語判斷特定心理或職業。

### P04｜人物關係、接觸與交集

| 骨架 | 一對一框架 | 主要工作與輸出 |
|---|---|---|
| B04.1 直接接觸關係 | F04.1 接觸歷史模型 | 記錄接觸時間、方式、來源及可信程度。 |
| B04.2 社交網與中間人 | F04.2 關係網分析 | 建立已知人物、群體、場所與機構的關係圖，標記未知邊。 |
| B04.3 關係變化與互動 | F04.3 互動變化分析 | 檢查衝突、控制、依賴或利益關係是否有獨立資料支持。 |
| B04.4 關係與犯罪的實際連接 | F04.4 關聯路徑驗證 | 驗證關係是否與事件相連，避免把社交接近視為犯罪證據。 |

### P05｜犯罪動機與行為目的

| 骨架 | 一對一框架 | 主要工作與輸出 |
|---|---|---|
| B05.1 動機類型及證據 | F05.1 動機假說矩陣 | 比較人際衝突、利益、報復、控制、偶發升級及其他可能解釋。 |
| B05.2 長期因素與直接觸發 | F05.2 動機形成模型 | 區分背景因素與事件觸發因素；每項都需要相應證據。 |
| B05.3 被害者選擇的可能原因 | F05.3 選擇動機分析 | 比較針對性、關係性、機會性等競爭假說。 |
| B05.4 犯後行為目的 | F05.4 犯後目的分析 | 獨立檢驗隱匿、延遲發現或其他可能目的，不由單一手法反推唯一動機。 |

動機與犯後目的須分開建模。同一行為可能有多種解釋；若沒有區辨資料，維持 UNKNOWN／NOT_TESTABLE。

## 3. 所有框架共用的資料契約

每個框架執行時必須產生以下欄位；不適用時明確填 N/A，不可默默省略。

1. **問題／主張 ID**：分析的確切問題，不用模糊的大題目替代。
2. **輸入資料與來源鏈**：原始來源、發布者、日期、引用／轉載關係、可取得性。
3. **狀態**：CONFIRMED、SOURCE_REPORTED、INFERRED、HYPOTHESIS、CONFLICTED、UNKNOWN、BLOCKED_BY_ACCESS、NOT_TESTABLE。
4. **目前解釋**：推論是如何由證據得出，且在哪一步需要假設。
5. **替代假說**：至少一個合理替代解釋；若不存在，須說明原因。
6. **反證與可推翻條件**：哪些資料會降低支持度、推翻或重開模型。
7. **區辨性資料**：最可能讓競爭假說排序發生改變的資料。
8. **輸出與下游依賴**：由哪個框架使用，會影響哪些判斷。
9. **驗收結果**：PASS、PARTIAL、BLOCKED 或 FAIL，並附可查的實際結果。
10. **回退／停止條件**：何時退回上游修正，何時換路徑，何時保留未解。

## 4. 故事模型與四條鏈

整體故事只能從各模組的輸出整合，不得先寫出單一故事再選擇性取證。

- **事件鏈：** 被害者背景 → 最後確認活動 → 未知事件區間 → 已確認的犯罪行為／發現事件 → 後續調查與身分確認。
- **人物與機構關係鏈：** 被害者、家人、同學／同事、熟識者、場所／機構、發現者、調查單位與媒體之間的已知及未知關係；未知行為人維持未識別角色。
- **能力鏈：** 已確認行為 → 必要技能 → 替代能力來源 → 職業群假說 → 區辨證據。
- **資訊與證據鏈：** 原始資料 → 直接採訪／官方文書 → 二手報導 → 轉載／論壇／自媒體 → 主張級核查。

每條鏈都需區分已知、推定、爭議與未知；同一主張的轉載不可計作多份獨立證據。

## 6. 假說與多版本模型

至少維持三類模型，並隨新證據更新：
- **M0 最小相容模型：** 只納入足以被目前證據支持的節點，未知部分保持空白。
- **M1 主要競爭模型：** 以一組明確、可測試的假設補足部分未知。
- **M2 替代模型：** 主動設計另一種合理解釋，檢查主模型是否只是偏好的故事。

比較指標包含：已確認事實覆蓋、矛盾數量與嚴重性、額外假設成本、時間／空間可行性、證據獨立性、可區辨性與反證承受力。不可把這些指標隨意加權後包裝成嫌疑人精確機率。

## 7. 工作流程與停損

1. 從 C0 明確定義本輪要解的具體子問題。
2. 讀取相關既有工作包與來源台帳，確認已知狀態。
3. 執行來源／事實前置閘門，避免把矛盾或傳聞送入高階模型。
4. 依十主軸覆蓋矩陣檢查是否漏掉重要分支。
5. 對當輪最重要的骨架節點選擇框架，而非一次跑完整套。
6. 生成競爭假說，列出能區分它們的資料。
7. 依資訊增益、可取得性、成本及風險排序下一步。
8. 執行後記錄新增證據、狀態變化、錯誤與阻塞。
9. 回到原始子問題驗收；只有證據狀態真的改變才能標為已解決。
10. 若連續兩輪只有同源重複結果，停止原搜尋路徑並改換資料類型、來源渠道或問題定義。
11. 不可存取的資料明確標為 BLOCKED_BY_ACCESS／HUMAN_ACTION_REQUIRED；不得把不可取得當作不存在。
12. 若新資料影響前提，退回相依框架修正，不只在結論末端加註。

## 8. 驗收門檻

- **結構驗收：** 10 條主軸；每條目前有 4 個有區別的骨架；每個骨架恰有一個主要框架模組。
- **範圍驗收：** 被害者、行為人能力、作案手法、關係、動機、環境、時間、證據、跨案、候選比較均被明確分工。
- **邏輯驗收：** 重要推論可追溯至來源及中間推論；有替代解釋和反證條件。
- **證據驗收：** 同源資料去重；原始證據未取得時不假稱已證實。
- **故事驗收：** 故事鏈含有明確未知節點，不為流暢性補造事件。
- **行動驗收：** 下一步是具體、可取得且有區辨價值的資料或測試，不是泛泛「繼續研究」。
- **結案驗收：** 以原始問題是否被回答為準，不以文件數或結構圖數量為準。
