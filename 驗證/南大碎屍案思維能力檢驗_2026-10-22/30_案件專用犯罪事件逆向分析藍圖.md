## 0. 藍圖總結

本案的分析目標不是無限收集文章或把已知報導串成流暢故事，而是建立可被新增證據修正的事件模型，並回答哪些線索能協助識別或排除行為人。

本藍圖把層級固定為：

- **最終調查目標 C0：** 以可靠證據識別或排除行為人；證據不足時允許維持未決。這是案件層級的方向，不是本研究可以不受限制地指認私人個體的授權。
- **本研究的可交付目標：** 建立可追溯的事實／證據模型、比較可區辨的事件假說，並找出能有效改變結論的下一項資料。公開資料不足時，交付可以是有邊界的部分解、排除某些模型或明確的資料阻塞。
- **主軸 P01–P10：** 十個主要分析責任方向；它們是目前的工作分類，不宣稱為唯一或普遍適用的犯罪學分類。
- **骨架 Bxx：** 主軸下的分析責任分支。目前草案配置 40 個骨架，但數量只是現況，不是完成品質的證明。
- **框架 Fxx：** 每個骨架目前配置一個主要框架。這個一對一結構須通過責任重疊審查；若同一責任被多個框架重複擁有，先整併／明確分工，不為維持數量而保留重複模組。
- **驗收：** 以原始問題的進展、證據區辨力、來源可追溯性與可重現的執行結果為準，不以文件數量、篇幅、搜尋次數或故事完整度代替。

「每主軸至少三個骨架」是本專案的內部結構檢查提示，不是學術定律或強制配額。若合理範圍內不足三個實質分支，不得為湊數創造空泛骨架；若有證據支持的責任必須再分，亦不應為維持每主軸四個而禁止擴充。結構先服從唯一責任與可驗收輸出。

## 1. 核心與十條主軸

### C0｜案件調查終極目標與本研究邊界

案件層級的終極目標是以足夠證據識別或排除行為人；本研究層級的目標則是提升公開資料的可驗證程度，重建有證據支持的事件結構，檢驗競爭假說並定位高價值資料缺口。不得將「找出行為人」解讀成必須靠推理產出姓名。沒有可靠證據時，不列私人嫌疑人名單、不把符合一般特徵者連結到本案，並把未決狀態當成正當結果。

| 主軸 | 方向 | 必須回答的問題 |
|---|---|---|
| P01 | 被害者與受害者背景 | 為什麼被害者的背景、生活及接觸範圍與案件有關？ |
| P02 | 行為人特徵、能力與限制 | 已知行為對能力、資源、技能及限制提出哪些最低要求？ |
| P03 | 犯罪行為與作案手法 | 有哪些行為可以重建，事件各階段的先後如何？ |
| P04 | 人物關係、接觸與交集 | 哪些人或群體具有可驗證的關係、接觸或接近機會？ |
| P05 | 犯罪動機與行為目的 | 哪些目的假說可以解釋犯罪與犯後行為？ |
| P06 | 環境、空間與作案機會 | 場所、動線及環境條件限制或支持哪些事件模型？ |
| P07 | 時間與事件順序 | 不同時間欄位、事件先後與可行時間窗口如何界定？ |
| P08 | 證據、來源與事實驗證 | 什麼是事實、來源所述、推論、假說或未知？證據是否獨立？ |
| P09 | 跨案件關聯與行為模式 | 是否有先行證據支持值得比較的案件母體，且相似特徵具區辨力並可獨立驗證？ |
| P10 | 候選假說比較、證據需求與排除 | 哪些已知或抽象候選假說可由合法、可靠的資料比較；哪些反證可排除它們？ |

主軸邊界與啟動門檻：
- P02 推估已知行為提出的最低能力需求及替代取得途徑；P10 比較可檢驗的候選假說。符合一般特徵不等於涉案；沒有足以支撐的行為證據時，P02 不輸出職業／人格定論，P10 不產生私人個體名單。
- P03 重建哪些行為可被證據支持；P05 比較可能的動機／目的。動機解釋不能代替行為證據，亦不能反過來當作證實動機的證據。
- P04 管理已可驗證的關係與接觸；P05 檢驗這些關係是否對特定動機假說有區辨價值。認識被害者不代表有犯罪動機。
- P01.4 的責任是判斷資料是否支持「被害者被特定選擇／機會性接觸」這類模型；P05.3 的責任是檢驗可能的選擇原因，兩者輸入輸出不得重複。
- P03.1 描述行為階段，P07.3 描述事件在時間上的先後與時長；前者不重新建立第二份時間線。
- P02.2 描述技能／資源需求與替代取得途徑，P06.4 描述這些資源與環境條件的關係，禁止重複維護同一份工具／資源清單。
- P06 分析空間可能性；P07 分析時間可能性。地理相鄰不等於事件順序，發現時間不等於實際放置時間。
- P08 是全案證據校正責任，但不能只作總括口號；必須維護主張層級的來源鏈、獨立性與反證記錄。所有主軸均需提供可被 P08 核查的輸入。
- P09 只在存在可驗證比較母體、明確比較規則與可區辨特徵時啟動，不因媒體聲量、網路相似故事或一般特徵而自動串案。
- P10 是研究中的假說比較與排除，不是民間偵查或公開指認的授權；本研究不發布未經可靠證據支持的私人個體嫌疑判斷。

## 2. 骨架—框架一對一對應表

每個框架模組使用同一個基本契約：**輸入 → 處理 → 輸出 → 驗收 → 未解／回退條件**。下表先定義各模組的唯一主要責任；框架內部可再向下拆分。

### P01｜被害者與受害者背景

| 骨架 | 一對一框架 | 主要工作與輸出 |
|---|---|---|
| B01.1 身分與基本背景 | F01.1 被害者基礎檔案 | 整理可確認的身分、生活、學習／工作背景；輸出來源可追溯的基本資料表。 |
| B01.2 日常生活與活動模式 | F01.2 生活基線模型 | 建立有來源支持的日常活動範圍與慣常模式；區分一般模式與例外。 |
| B01.3 事件前活動及接觸 | F01.3 事件前活動重建 | 整理最後確認活動、直接接觸與時間錨點；不把傳聞補成行蹤。 |
| B01.4 被害者選擇與風險背景 | F01.4 被害者選擇分析 | 比較針對性、關係性、機會性等假說，並列出區辨性證據。 |

### P02｜行為人特徵、能力與限制

| 骨架 | 一對一框架 | 主要工作與輸出 |
|---|---|---|
| B02.1 技能與知識需求 | F02.1 能力需求分析 | 從已確認行為推估最低必要技能，列出非職業性替代來源。 |
| B02.2 工具、資源與取得條件 | F02.2 資源條件模型 | 檢查工具／資源的特定性、取得門檻及多種替代來源。 |
| B02.3 規劃、熟練與應變 | F02.3 行為能力分析 | 區分有證據的預先規劃、操作熟練度及臨場反應，不以結果反推專家身分。 |
| B02.4 身體條件與個人限制 | F02.4 行為人限制模型 | 只在行為或可靠資料提供依據時，評估身體條件、時間、資源等限制。 |

職業推算規則：先建立「行為 → 必要技能 → 可能取得途徑 → 候選職業群 → 區辨證據」的推論鏈。沒有職業專屬性或獨立證據時，只能標記為待比較假說，不能認定職業、人格或身分。

### P03｜犯罪行為與作案手法

| 骨架 | 一對一框架 | 主要工作與輸出 |
|---|---|---|
| B03.1 犯前、犯中、犯後序列 | F03.1 行為序列模型 | 把事件拆成階段與可觀察行為，標示順序確定度與未知區間。 |
| B03.2 接近、互動及犯罪發生 | F03.2 犯罪行為重建 | 根據物證、證言與可核驗紀錄，建立可能行為順序及替代版本。 |
| B03.3 犯後處置與現場變化 | F03.3 犯後處置分析 | 檢查是否確有處置、隱匿或現場變動；不預設行為目的。 |
| B03.4 作案手法、個人化行為與布置 | F03.4 行為分類鑑別 | 區分完成犯罪所需的作案手法、可能的個人化行為、現場布置與其他解釋。 |

本主軸輸出是「做了什麼、何者可證、順序如何、還缺什麼」，不是單憑描述性詞語判斷特定心理或職業。

### P04｜人物關係、接觸與交集

| 骨架 | 一對一框架 | 主要工作與輸出 |
|---|---|---|
| B04.1 直接接觸關係 | F04.1 接觸歷史模型 | 記錄接觸時間、方式、來源及可信程度。 |
| B04.2 社交網與中間人 | F04.2 關係網分析 | 建立已知人物、群體、場所與機構的關係圖，標記未知邊。 |
| B04.3 關係變化與互動 | F04.3 互動變化分析 | 檢查衝突、控制、依賴或利益關係是否有獨立資料支持。 |
| B04.4 關係與犯罪的實際連接 | F04.4 關聯路徑驗證 | 驗證關係是否與事件相連，避免把社交接近視為犯罪證據。 |

### P05｜犯罪動機與行為目的

| 骨架 | 一對一框架 | 主要工作與輸出 |
|---|---|---|
| B05.1 動機類型及證據 | F05.1 動機假說矩陣 | 比較人際衝突、利益、報復、控制、偶發升級及其他可能解釋。 |
| B05.2 長期因素與直接觸發 | F05.2 動機形成模型 | 區分背景因素與事件觸發因素；每項都需要相應證據。 |
| B05.3 被害者選擇的可能原因 | F05.3 選擇動機分析 | 比較針對性、關係性、機會性等競爭假說。 |
| B05.4 犯後行為目的 | F05.4 犯後目的分析 | 獨立檢驗隱匿、延遲發現或其他可能目的，不由單一手法反推唯一動機。 |

動機與犯後目的須分開建模。同一行為可能有多種解釋；若沒有區辨資料，維持 UNKNOWN／NOT_TESTABLE。

### P06｜環境、空間與作案機會

| 骨架 | 一對一框架 | 主要工作與輸出 |
|---|---|---|
| B06.1 場所角色與位置關係 | F06.1 場所分類模型 | 分別標記候選犯罪地、處置地、發現地、報案地及搜尋地，禁止混用。 |
| B06.2 接近、離開與移動可行性 | F06.2 空間可行性分析 | 檢驗各事件模型的移動條件是否可行；沒有依據不推斷實際路線。 |

|---|---|---|

### P09｜跨案件關聯與行為模式

**啟動閘門：** 先確認可合法取得的候選案件範圍、資料覆蓋、各案來源品質與特徵的區辨力。若比較母體不完整或只有媒體形容詞／網路推測，標記 NOT_TESTABLE，不進行串案結論。

| 骨架 | 一對一框架 | 主要工作與輸出 |
|---|---|---|
| B09.1 候選案件與比較範圍 | F09.1 案件比較母體 | 界定比較期間、區域、資料來源及納入／排除條件。 |
| B09.2 行為相似度與區辨力 | F09.2 行為特徵比較 | 區分常見行為與真正具有區辨力的特徵。 |
| B09.3 時空與其他客觀關聯 | F09.3 跨案時空模型 | 比較可核驗時間、位置及物證／紀錄關聯。 |
| B09.4 跨案連結的替代解釋 | F09.4 串案假說驗證 | 主動檢查巧合、資料選擇偏差及相反證據；沒有獨立依據時不宣稱同一行為人。 |

### P10｜候選假說比較、證據需求與排除

**啟動閘門：** 只比較由可靠線索合理產生、且有可驗證資料可以區分的假說。公開資料研究應優先比較事件模型與證據解釋，不把姓名、職業、居住區域或符合一般描述當成候選資格；涉及私人個體的實際指認應留給有權限的正式調查單位。

| 骨架 | 一對一框架 | 主要工作與輸出 |
|---|---|---|
| B10.1 候選對象產生 | F10.1 候選來源模型 | 只依合法且可靠的案件線索形成待查方向，不以人群刻板特徵點名。 |
| B10.2 候選與證據比對 | F10.2 候選假說矩陣 | 逐項比較符合、衝突、缺漏及替代解釋。 |
| B10.3 排除條件與反證審查 | F10.3 排除條件驗證 | 查找不在場、時間不可能、證據矛盾及其他排除性材料。 |
| B10.4 下一步調查行動排序 | F10.4 調查價值排序 | 以預期區辨力、可取得性、成本、風險和決策影響決定下一步。 |

## 3. 所有框架共用的資料契約

每個框架執行時必須產生以下欄位；不適用時明確填 N/A，不可默默省略。

1. **問題／主張 ID**：分析的確切問題，不用模糊的大題目替代。
2. **輸入資料與來源鏈**：主張 ID、來源 ID、證據／文件 ID、發布者或持有機構、日期、原始／轉載關係、可取得性、完整性及驗證方式。每個原子主張要連到具體來源位置，不能只連一個長篇文章首頁。
   - 同時記錄來源評估維度：距離事件的時間、第一手／轉述程度、原件真偽可驗性、來源獨立性、所支持主張的範圍，以及有無相反材料。機構聲望或多站轉載數量均不能單獨決定某項主張為真。
3. **主張狀態**：PRIMARY_SOURCE_VERIFIED（原始材料來源及版本可追溯）、OFFICIAL_STATEMENT（已定位的官方公開說法）、SOURCE_REPORTED（媒體／受訪者所述）、INFERRED（明示推論鏈）、HYPOTHESIS（可反駁假說）、CONFLICTED（來源或主張相衝突）、UNKNOWN（尚不清楚）、BLOCKED_BY_ACCESS（因權限／取得限制受阻）、NOT_TESTABLE（現有資料無法區分）。狀態描述主張目前的證據條件，不等同主觀可信度分數。
4. **目前解釋**：推論是如何由證據得出，且在哪一步需要假設；將觀察、推論與解釋分成不同句／欄位，避免用同一項推論作為自身的獨立證據。
5. **替代假說**：至少一個合理替代解釋；若不存在，須說明原因。
6. **反證與可推翻條件**：哪些資料會降低支持度、推翻或重開模型。
7. **區辨性資料**：最可能讓競爭假說排序發生改變的資料。
8. **輸出與下游依賴**：由哪個框架使用，會影響哪些判斷。
9. **驗收結果**：PASS、PARTIAL、BLOCKED 或 FAIL，並附可查的實際結果。
10. **回退／停止條件**：何時退回上游修正，何時換路徑，何時保留未解。

## 4. 故事模型與四條鏈

整體故事只能從各模組的輸出整合，不得先寫出單一故事再選擇性取證。

- **事件鏈：** 被害者背景 → 最後確認活動 → 未知事件區間 → 已確認的犯罪行為／發現事件 → 後續調查與身分確認。
- **人物與機構關係鏈：** 被害者、家人、同學／同事、熟識者、場所／機構、發現者、調查單位與媒體之間的已知及未知關係；未知行為人維持未識別角色。
- **能力鏈：** 已確認行為 → 必要技能 → 替代能力來源 → 職業群假說 → 區辨證據。
- **資訊與證據鏈：** 原始資料 → 直接採訪／官方文書 → 二手報導 → 轉載／論壇／自媒體 → 主張級核查。

每條鏈都需區分已知、推定、爭議與未知；同一主張的轉載不可計作多份獨立證據。

## 6. 假說與多版本模型

使用以下模型槽位管理假說，但不強迫每一個子問題都湊足三個故事：
- **M0 最小相容模型：** 只納入足以被目前證據支持的節點，未知部分保持空白。
- **M1 主要競爭模型：** 當資料容許時，提出能與 M0 或現有解釋競爭、且有不同可觀察預期的假說。
- **M2 替代／反向模型：** 對高影響結論主動測試一個不同解釋或「目前證據不足以判定」模型，檢查主模型是否只是偏好的故事。

對會影響核心方向的結論，原則上需比較至少兩個實質不同、可被資料區分的解釋；若現有資料連一個合理替代模型都無法具體化，必須說明原因與可判定性上限。M0／M1／M2 是組織工具，不是要求虛構三種情節。

比較指標包含：已確認主張覆蓋、重大矛盾、額外假設數量／強度、時間／空間相容性（僅在輸入過閘後）、來源獨立性、區辨資料可得性及反證承受力。先逐項描述差異；不得把未校準的指標任意加權成「嫌疑人機率」或看似精確的總分。若無法合理量化，使用定性裁定並公開理由。

## 7. 工作流程與停損

1. 從 C0 明確定義本輪要解的具體子問題。
2. 讀取相關既有工作包與來源台帳，確認已知狀態。
3. 執行來源／事實前置閘門，避免把矛盾或傳聞送入高階模型。
4. 依十主軸覆蓋矩陣檢查是否漏掉重要分支。
5. 對當輪最重要的骨架節點選擇框架，而非一次跑完整套。
6. 生成競爭假說，列出能區分它們的資料。
7. 依資訊增益、可取得性、成本及風險排序下一步。
8. 執行後記錄新增證據、狀態變化、錯誤與阻塞。
9. 回到原始子問題驗收；只有證據狀態真的改變才能標為已解決。
10. 若連續兩輪只有同源重複結果，將其視為本專案的操作性停損提示，重新判斷來源渠道、問題定義與預期資訊價值；兩輪不是普遍學術定律，也不是在高價值新線索即將出現時機械停止的命令。
11. 不可存取的資料明確標為 BLOCKED_BY_ACCESS／HUMAN_ACTION_REQUIRED；不得把不可取得當作不存在。
12. 若新資料影響前提，退回相依框架修正，不只在結論末端加註。

### 10.2 證據更新與依賴傳播流程

```text
NEW MATERIAL
  → authenticity / provenance / completeness check
  → extract atomic claims and link Source-ID / Claim-ID / Evidence-ID
  → compare with existing claims and identify source dependence
  → classify change: new / corroborates / conflicts / no added value
  → map affected upstream and downstream frameworks
  → rerun only impacted analyses + relevant regression checks
  → record what changed / did not change / remaining blockers
  → review original target and the next discriminating action
```

同源轉載應連回既有來源鏈，不重複計算為互證；原始材料的真偽、日期、完整性或引用關係未核驗時，不得因其文字看似具體而自動改變模型。新資料若無法改變任何核心決策，也沒有完成必要的來源核驗，應記錄低增益並考慮停損。新證據若改變上游前提，只重開相依分析與必要回歸，不全套重跑，也不只在結論末端加警語。

### 10.3 決策偏誤與競爭假說控制

對高影響結論，記錄目前較受支持的解釋、最有力的替代解釋、可能推翻當前解釋的資料，以及為何下一步行動能區分各模型。主動「考慮相反解釋」並保留決策理由；這不能消除所有認知偏誤，也不表示所有假說一樣合理。沒有可取得的區辨資料時，保留 NOT_TESTABLE。

2. **U.S. Office of Justice Programs / National Institute of Justice (2019), National Best Practices for Implementing and Sustaining a Cold Case Investigation Unit** — https://www.ojp.gov/library/publications/national-best-practices-implementing-and-sustaining-cold-case-investigation 。這是冷案單位的規劃、建立、運行和支援指南，不是針對本案的調查資料。本藍圖只借鑑工作範圍、資源、交接及可執行狀態管理，不直接移植美國制度。

4. **College of Policing, Investigation process—Building and testing hypotheses** — https://production.copweb.aws.college.police.uk/app/investigation/investigation-process 。其公開摘要指出，同一組材料可能容納不同初始假說，替代假說可協助產生查證路徑及測試其他解釋。本藍圖要求假說必須有不同、可檢驗的預期，而非同一故事換句話說。
5. **Federal Bureau of Investigation, Behavioral Analysis** — https://www.fbi.gov/how-we-investigate/behavioral-analysis 。FBI 對該職能的描述包含動機、被害者選擇、行為複雜度、具體行動與事件順序分析，以及對訪談和調查策略的支援。本藍圖將行為分析定位為支援證據調查與資源排序的方法，不把側寫當成獨立識別嫌疑人的捷徑。

這些來源支援的是決策品質、證據完整性、假說競爭、冷案管理及行為分析職責；它們不驗證本藍圖的骨架數量，也不證明本案任何動機、職業或行為人假說為真。
