# 專題研究工作區

- 類型：PROJECT_WORKSPACE_INDEX
- 狀態：CURRENT_ENTRY / NEW-PROJECT-TRIAL-PENDING
- 唯一責任：列出採新規則開案的專題工作區；不取代 forAVAr 的全域文件索引或變更追溯表。

## 開案規則

每個新專題先建立自己的資料夾與唯一 ID，先完成題目內研究，再於結案後抽取基礎屬性，最後才比對 forAVAr 現有能力。不同題目可使用不同分析分支；不得為了統一格式而強迫採用相同研究方法。

起始模板：[專題工作區資料夾與分類模板](./_模板/專題工作區資料夾與分類模板_v0.1.md)。設計與採納閘門：[專題隔離與基礎屬性歸因流程規劃](../參考資料/解析文檔/專題隔離與基礎屬性歸因流程規劃_2026-10-22.md)。

## 新專題命名

建議格式：`PRJ-YYYYMMDD-短題目`，資料夾路徑為 `專題研究/PRJ-YYYYMMDD-短題目/`。開案時至少建 `README.md`、`00_開案契約與範圍.md`、`01_來源與證據清冊.md`；分析分支按實際題目與研究方法建立，結案時才建立屬性抽取與系統納入評估檔。不需預先建立空白的未用文件。

## 專題清單

目前尚未有按此命名規則新建並結案的專題。既有南大案件在 [驗證/南大碎屍案思維能力檢驗_2026-10-22](../驗證/南大碎屍案思維能力檢驗_2026-10-22/) 已有獨立資料夾，保留原位作為既有案例，不搬移或另複製一份到本目錄。

## 邊界

本索引只負責專題工作區，不維護跨專題問題清單、系統能力登錄、SOP 狀態或完整參考資料索引。可遷移的候選屬性需回鏈專題與來源，系統狀態以 forAVAr 對應的唯一權威文件為準。
