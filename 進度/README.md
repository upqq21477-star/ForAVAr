# 進度

本資料夾集中記錄 forAVAr 主系統的施工進度、目前狀態、已完成項目與待辦事項。

## 維護規則

- 進度紀錄只記錄實際狀態；未執行、未驗證或未完成的項目不得標記為完成。
- 不複製整份藍圖、功能清單或問題清單；以主系統文件作為唯一依據，避免資料分叉。
- 更新進度時，標明日期、對應項目、狀態與可追溯的文件或提交紀錄。
- 測試、驗證及暫存材料若需要長期保存，依專案規則存放於 forAVArb，不混入主系統。
