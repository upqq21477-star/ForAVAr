# 雙向結構還原與缺漏推導｜獨立研究工作入口

**研究主題：複雜系統解構、世界模型建構、因果閉環與模擬驗證。**

本課題獨立於「AI 理解可視化與框架編輯介面」。前者研究如何理解、解構、推導和驗證複雜世界；後者研究如何把已形成的理解呈現給人並供人編輯。兩者不得合併成同一企劃，也不得以圖形介面代替本課題的建模與閉環方法。

## 權威文件

- [研究企劃：複雜系統解構與模擬世界閉環](./00_複雜系統解構與模擬世界閉環研究企劃.md) — 本課題唯一現行主文件，包含問題定義、方法骨架、因果與資料閉環、模擬驗收、分階段研究及停止條件。
- [外部研究與技術標準索引](./外部研究與技術標準索引.md) — 研究方法的外部依據、適用範圍及不可外推的限制。

## 研究邊界

- 研究對象是複雜系統的結構、規則、狀態、資料、時間、因果機制和運行結果；遊戲系統是重要驗證案例，不是唯一適用對象。
- 逆向還原從已有文件、程式、資料和可觀察行為重建世界結構；正向缺漏推導從目標、約束及已知規則找出尚未定義的必要機制。
- 本研究只把候選提升為經確認規則，不能把推測當事實；「閉環」必須限定在明確的用途、範圍、解析度與情境中。
- 本課題不規劃視覺化介面，不改動其他專案，不把靜態閱讀或紙上推演宣稱成實際執行結果。
- 本資料夾只維護一份現行研究企劃與一份來源索引；新發現優先整合回權威文件，不另建重複版本。
