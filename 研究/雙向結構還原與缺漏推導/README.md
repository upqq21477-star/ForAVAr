# 雙向結構還原與缺漏推導｜獨立研究工作入口

**研究主題：從現實與成熟領域中歸納規律，建立最小系統總覽，再以總覽反向推導具體模型的缺漏。**

本課題獨立於「AI 理解可視化與框架編輯介面」。本課題研究的是世界規律抽象、因素與機制歸納、最小充分模型和缺漏推導；可視化課題研究的是理解結果的呈現和編輯。兩者不可合併。

## 權威文件

- [現實規律抽象與最小系統總覽研究企劃](./00_複雜系統解構與模擬世界閉環研究企劃.md) — 唯一現行主文件。包括通用系統總覽、關係型態、最小充分模型，以及以戰力因素為例的反向缺漏推導。
- [外部研究與技術標準索引](./外部研究與技術標準索引.md) — 只保留與現實抽象、系統模型、戰力因素、因果／資源流及方法評估有關的來源。

## 研究規則

- 歷史資料只用於追溯來源、版本和已知依據；不把歷史事件或開發流程本身當成研究對象。
- 先總結共通規律與作用機制，再選取適用部分建立具體模型；不把一個領域的分類硬套到所有領域。
- 「因素清單」不等於「因果模型」。必須說清因素如何透過機制影響結果。
- 追求最小充分模型，不追求無限制列舉。若因素不影響指定目標與尺度，可合併、降級或排除，並保留適用條件。
- 候選缺口要有依據和裁決；未知不得自行補成事實。
- 本課題不規劃可視化介面，不修改 P1／P2，不宣稱靜態研究等於已完成模擬或實證驗證。
- 只維護一份主企劃與一份來源索引。新結論優先整合回權威文件，不新增平行版本。
