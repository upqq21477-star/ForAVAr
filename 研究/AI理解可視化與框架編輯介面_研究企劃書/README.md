# AI 理解可視化與框架編輯介面研究企劃｜集中工作資料夾

## 本資料夾的定位

本資料夾是本企劃後續更新的集中工作入口。既有原路徑的檔案一律保留原狀，不搬移、不刪除、不覆寫；本資料夾收錄當前基線副本，後續企劃相關的新規格、研究判斷與更新，統一先在本資料夾內完成。

為避免雙重真實來源：原路徑代表未改動的歷史基線；本資料夾代表集中整理後的工作基線。兩者不同時，自本資料夾的版本清冊與變更紀錄判讀，不將修改自動回寫到原路徑。

## 當前基線與證據界線

1. 主企劃、資料契約與比較研究的集中副本，初始版本分別為 0.8.0-draft、0.2.2-draft、0.5.0。
2. 歷史驗證記錄只支持其標記的舊基線：Schema meta-validation 與三個 fixture 結果；18 個原型斷言只適用於 validator v0.1 與 cross-object rules v0.2.0-draft。
3. 新候選 validator v0.2 與 cross-object rules v0.3.0-draft 尚未執行。不得把舊測試結果宣稱為新候選已通過。
4. 產品 UI、端到端互動、儲存/載入、行動裝置可用性和正式 Runtime 均未驗收。

## 後續更新規則

- 先讀本資料夾的企劃書、基線清冊與有限工作計畫，再決定要改哪個文件。
- 每次更新先寫明問題/證據/決策變更；無新證據、無需求變更、無具體缺陷時，不做無目的重審。
- 不覆寫舊的驗證結果；新增結果檔並標註被測檔案版本、Git blob SHA、命令/環境、結果與未覆蓋範圍。
- 未執行一律標記 NOT_RUN；推演、靜態檢查、單元測試、端到端測試與使用者驗收分開記錄。
- 先完成有限的一輪候選驗證與缺陷修正；到達既定停止條件後，轉入介面需求與實作規劃，不形成無限驗證循環。
