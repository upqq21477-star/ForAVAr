## 維護規則

- 只在本資料夾修改／新增企劃工作檔；外部原始來源路徑不覆寫。
- 只保留一份現行驗證器、一份現行跨物件規則、一份案例清單、一份有限驗收計畫和一份整合結果。
- 新增缺陷時更新現行規格或測試；歷史修正理由與舊結果合併進「演進與驗收總結」，不再建立每輪獨立的審查／變更／交接文件。
- 每個 PASS 必須有實際執行證據；靜態檢查不能替代程式測試，舊基線 PASS 不得轉移到現行候選。
- 不使用付費遠端執行服務、GitHub Actions 或新 API 作為必要依賴，除非專案負責人另行批准。
