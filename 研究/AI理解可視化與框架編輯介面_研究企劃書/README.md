## 目前狀態與證據邊界

1. JSON Schema 0.2.0 的 Draft 2020-12 meta-validation 曾以 `jsonschema 4.26.0` 通過；此結果只支持該精確 Schema 基線。
2. 3 個精確 fixture 結果及 18 個舊版原型斷言有歷史報告可追溯。18 個 PASS 僅適用於 validator v0.1 + cross-object rules v0.2.0-draft，不可轉用到新候選。
3. 目前候選是 validator v0.2.1 + cross-object rules v0.3.0-draft；兩者都尚未執行。靜態修正不代表語法或行為測試通過。
4. 正式 Runtime、UI 互動、手機使用性、版本發布端到端流程及使用者任務驗收均未完成。

## 更新規則

- 未來本企劃的所有工作產物都只能新增或修改在本資料夾內；依用途放入現有子目錄。除非有明確架構決策，不再建立第二套工作副本。
- 不改動既有來源位置的系統檔案。來源 SHA 只用於追溯，不能默默回寫來源檔案。
- 不覆寫歷史測試報告；每輪新結果新增新報告，固定 validator、rules、schema 的 Git blob SHA、執行環境、命令、逐案例結果與限制。
- 狀態只可使用有證據支持的 `PASS`、`FAIL`、`BLOCKED`、`NOT_RUN`；靜態閱讀、桌上推演與實際執行要分開標示。
- 當規定的有限驗收完成後，依停止條件進入 UI／編輯器需求規格，不形成無限重審循環。
