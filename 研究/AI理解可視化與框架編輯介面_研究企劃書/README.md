# AI 理解可視化與框架編輯介面｜唯一工作入口

本資料夾是本企劃唯一權威工作位置。接手時按以下順序讀取，不必追讀根目錄舊版或歷史迭代。

## 正式定位

圖形認知層是既有認知架構上的人類理解與操作延伸。它可以有自己的圖形表示、資訊架構、引導／固定的使用者任務流程及錯誤復原設計，用來降低操作門檻；它不是與既有認知核心競爭的另一套機器推理核心。AI 的推理仍依任務適配，使用者修改則透過版本化契約回傳核心。

## 目前狀態（2026-10-28）

**施工狀態：唯讀可視化原型已獲准開工；候選驗證器仍 BLOCKED／NOT_RUN。** 原型只讀取使用者選取的 JSON 並在本機畫面呈現，不修改模型、不發布、不回傳核心；編輯、版本發布及核心整合仍需正式資料驗證與後續閘門。

- 修正前基線的靜態前置檢查：7/7 PASS（2026-10-27 歷史紀錄）。2026-10-28 對現行 Schema `$id` 的唯一權威路徑作了修正，現行 SHA 需重新驗證，不承接舊 PASS。
- 現行 Schema meta-validation、Python 驗證器、CLI、回歸及定向測試：BLOCKED／NOT_RUN。
- 目前 fixtures：8 個可定位，2 個有效／證據、6 個負向；歷史提及的第 7 個負向 fixture 未定位。
- 研究關閉條件：資料契約 → 使用者任務 → 圖形互動 → 核心接口 → 閉環模擬 → 人類使用者驗收 → 證據／版本同步。未達最終條件時只能標為 PARTIAL，不得標 ACCEPTED。

## 維護與驗收規則

- 本資料夾只保留一份現行驗證器、現行跨物件規則、案例清單、有限驗收計畫及整合結果。
- 根目錄舊企劃、資料契約、方法比較及 v0.4 介面整合稿均已轉成非權威指引；原始長稿已存入 forAVArb1/archive。根目錄舊 Schema／關係規則副本已移除，唯一現行副本位於本資料夾。
- 每個 PASS 必須有實際執行證據；靜態檢查不能替代程式測試，舊基線 PASS 不得轉移至現行候選。驗證器環境受阻，只阻擋依賴其判定的編輯／發布／核心回傳，不得一併阻擋安全的唯讀可視化施工。
- 施工優先：每個工作包必須先交付可見的程式或功能產物；完成後只做一次針對性讀回／範圍核對。無新程式差異、新證據或環境變化，不重複執行相同檢查。
- 不使用付費遠端執行服務、GitHub Actions 或新 API 作為必要依賴，除非負責人另行批准。
- 研究記錄中的圖形／互動流程屬人類使用者側設計；變更是否進入正式核心，必須依明確接口、影響分析與驗收決定。
- 交接必須以「已交付的產物 → 下一個施工單元 → 具體路徑／完成條件」為主；阻塞檢查只記錄一次，除非取得新環境／新證據才重開。不得以重寫交接或重列測試命令代替進度。
