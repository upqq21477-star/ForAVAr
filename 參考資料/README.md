## 1. AI 開工順序

1. 讀取[文件與分支索引](./文件與分支索引.md)，依當前主題定位唯一 MASTER。
2. 讀取[版本治理與分流規範](./版本治理與分流規範.md)，遵守 DOC_ID、版本上限、分支、字元閾值與雙向引用規則。
3. 查[變更追溯總表](./變更追溯總表.md)，確認現行狀態及近期變更。
4. 讀取對應 MASTER 的摘要、目錄、分支索引和未決事項；只按需載入當前工作所需的 CURRENT BRANCH 或 SOURCE。
5. 只有在需要恢復內容、比對歷史或稽核授權時，才調閱 BACKUP_ONLY 舊版。

不得以檔名較新、提交時間較晚或正文寫得較完整就推論其權威性；以主軸索引、文件 ID、狀態和證據為準。
