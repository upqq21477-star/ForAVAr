## 5. 分批分析順序

1. B1 封包 B 結構與文字：已完成初步解壓、四成員盤點、提案邊界與核心概念蒸餾。
2. B2 封包 B 完整性與雙格式比較：待完成 CRC、Markdown／DOCX 逐段差異及引用檔名一致性。
3. A1 封包 A 讀取：待取得完整 ZIP 位元組；不可只依 HANDOFF 推定內部內容。
4. A2 封包 A 分批解析：取得成員清單後，先解析 manifest、啟動規程、Current／藍圖，再按工具、程式、測試、交接產物分批。
5. C1 跨文件去重：只比較相同概念與相同責任，不因字詞相似就判定功能重複。
6. C2 最終蒸餾：生成不重複的核心知識索引，保留來源檔名、段落／路徑、版本、證據等級及未知事項。
