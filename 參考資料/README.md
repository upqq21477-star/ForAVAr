## 1. AI 開工順序

1. 讀取[文件與分支索引](./文件與分支索引.md)，依當前主題定位唯一 MASTER。
2. 讀取[版本治理與分流規範](./版本治理與分流規範.md)，遵守 DOC_ID、版本上限、分支、字元閾值與雙向引用規則。
3. 對非瑣碎或需要持久化的任務，先查[對話流程列表](./對話流程列表.md)選擇流程，再依[固定流程與演化管理規範](./SOP固定流程與演化管理.md)執行；只載入當前任務需要的 SOP。
4. 查[變更追溯總表](./變更追溯總表.md)，確認相關主題現行狀態及最近事件。
5. 讀取對應 MASTER 的摘要、目錄、分支索引和未決事項；只按需載入 CURRENT BRANCH 或 SOURCE。
6. 只有在需要恢復內容、比對歷史或稽核授權時，才調閱 BACKUP_ONLY 舊版。

不得以檔名較新、提交時間較晚或正文寫得較完整就推論其權威性；以主軸索引、文件 ID、狀態和證據為準。

**更新硬性前置閘門：** 凡要改變功能、邏輯、能力、流程或架構，寫入前必須依 [SOP-META-001](./SOP固定流程與演化管理.md#更新任務的增量修正與職責歸位) 先盤點[能力登錄](./功能清單_基礎能力覆蓋登錄_v0.1.json)、[P1／P2 功能骨架映射](./解析文檔/架構映射/P1-P2-功能骨架樹-全面重整版.md)及相關 SOP／問題 ID；記錄已檢查的既有能力、重疊／衝突、實際缺口，以及為何不能修正／擴充既有能力。**盤點未完成或新增理由無證據時，禁止新增，標記 BLOCKED／待查；先修正或擴充既有節點。** 只有純讀取或不改變語意的機械修正走最小路徑。
