## 4. 閱讀與引用規則

1. 研究或開發 P2 封包相關概念時，先讀[P2 封包紀錄整合主文件](./解析文檔/P2_封包紀錄整合主文件.md)；一般解析工作則先讀本索引、[去重與蒸餾規範](./去重與蒸餾規範.md)及[唯一職責矩陣](./解析文檔/跨文件重疊與唯一職責矩陣.md)。
2. 追查原始來源身分時使用[原始檔案清冊](./原始檔案/清冊.md)；按步驟施工時使用[解析流程](./解析步驟流程.md)。
3. ZIP B 的數值與格式差異以專屬稽核報告為準；跨文件狀態與蒸餾結論看主分析報告。
4. 錯誤、矛盾、假陽性及阻塞以固定標記 ID 追蹤；全庫數量、雜湊、重複與連結狀態以最新整體稽核為準。
5. 原始封包及可直接驗證的來源內容優先於 HANDOFF 摘要或企劃提案。除非有實作／測試證據，不得把提案或外部研究描述成 P1／P2 的既有能力。
