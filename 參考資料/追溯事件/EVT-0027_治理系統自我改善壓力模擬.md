## 3. 模擬結果的精確範圍

- 五組不同種子，各 10,000 個候選更新；比較六種治理策略。
- 另執行一組 V5 的 100,000 更新敏感度檢查，用於觀察分段、索引與紀錄量成長。
- 這些數值來自合成更新類型、內容長度、檢查命中率及交易回退機率。它們不是 ChatGPT 模型錯誤率、實際 GitHub 寫入成效或真實服務容量指標。
- 對抗測試顯示「兩檢查器」若有共因失效，零漏放結果不可靠；此發現已納入報告，不將雙檢查器視為充分的獨立證據。
- 自動更新目前仍是候選治理設計；文件和模擬器已建立，不代表自動 Runtime、持續背景維護或基礎模型權重自我更新已實作。

## 4. 驗收與未驗證邊界

驗收：報告和兩個 Python 工具均已建立；問題清單、SOP 清單、README、全域索引、責任矩陣與台帳已同步；所有受檢文件維持在 8,000 字元限制內。
