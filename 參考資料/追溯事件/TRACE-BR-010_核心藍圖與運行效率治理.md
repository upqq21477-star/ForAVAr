- 運行模式：中控＋獨立系統、中控＋角色、工作封包、分層插件、C′；新增按任務選擇的協作拓撲。

- 載入最小化：LOAD-0–3，按需讀取；短任務不建立完整封包。
- 紀錄最小化：一份 Run Record 集中存目標、狀態、變更、驗收、恢復點；不將不同欄位強制拆成多份文件。
- 生命週期：審查日期、保留條件、封存、阻塞退場、永久清除授權、恢復與檢查點。
- 驗收：一致案例、相同工具和權限；量測品質、成本、範圍擴散、載入和恢復，不由文件完成度推論 Runtime。
