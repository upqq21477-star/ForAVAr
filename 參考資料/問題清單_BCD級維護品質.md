|---|---|---|

| **PR-044 命名、顯示或分類不一致** | 同一能力使用多個名稱，或不同概念共享名稱。 | 穩定 ID、唯一正式定義，別名只作搜尋導航。PARTIAL |
| **PR-045 重複提問或過度打斷** | 把低風險歧義當成必須阻塞的問題。 | 只對會改變結果、風險、範圍或授權的關鍵歧義澄清；其他情境明示假設後前進。DESIGN_DEFINED_UNVERIFIED |
| **PR-046 視圖形式與任務複雜度不匹配** | 簡單任務被過度圖表化，複雜依賴卻無法直觀檢查。 | 依任務選文字、表格或圖表；所有視圖回指權威來源。PARTIAL |
| **PR-047 文件格式、目錄或描述增加閱讀成本** | 同一結論散落在多處，讀者難以找到唯一入口。 | README 作導航、責任矩陣分工、專題文件負責細節；不重複貼完整背景。PARTIAL |
