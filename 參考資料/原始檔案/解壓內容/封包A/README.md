## 歸檔規則

1. 原始 ZIP 是唯一原始來源；本目錄如日後用作解壓副本，所有成員須保留原始路徑、大小、CRC32、SHA-256、格式和解析狀態。
2. 每個成員只指定一個 canonical 分類位置；其他分類以連結／索引引用，不複製全文。
3. 根據實際內容、依賴和呼叫關係分類，不只看檔名。
4. 不可解讀、缺失引用或未驗證項目需保留在清冊，明列原因及狀態。
5. 完整性驗證、靜態語法解析、業務語意檢查、測試執行與 Runtime 驗收分開標記。
6. 只有在按需歸檔確有價值且驗收條件明確時，才建立解壓副本；不為了「看起來完成」而重複存放整個程式樹。
