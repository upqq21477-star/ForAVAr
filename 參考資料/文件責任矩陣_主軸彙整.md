## 2. 現行責任模型

README 負責導航；MASTER 彙整共同結論和分支索引；BRANCH 保存單一角度的細節證據；SOURCE 保存不可變原始輸入；問題清單保存問題 ID 與狀態；變更追溯總表保存文件變更事件。任何一份文件不得透過摘要取代其他文件的唯一責任。

## 3. 長度與引用驗收

詳細矩陣超過 8,000 字元，先標記 `SPLIT_PENDING`，目前不刪除、不改寫其歷史段落。取得完整出鏈／入鏈圖、按主題分流並核對錨點後，才將本索引設為完整的唯一引用入口。現行全庫回鏈覆蓋標記 `PARTIAL`。
