## 2. 目前治理狀態

問題清單正文約 19,539 字元，超過 8,000 字元硬閾值。為防止截斷或遺漏，當前正文仍保留原狀且不得刪除；標記 `SPLIT_PENDING`。後續應依穩定問題 ID 及 S/A/B/C/D 嚴重度分流成子清單，保留唯一 ID、原始證據、跨表連結和既有引用錨點；分流完成並驗收前，問題清單正文仍是權威來源。

## 3. 分流要求

各子清單上限 8,000 字元；本索引不複製問題條目正文。分流後索引只列本文件，問題 ID 連到對應子清單；所有指向舊錨點的引用在遷移完成前維持可解析。不能因摘要或索引建立成功就標記問題已解決。
