### 4.2 長段落完全重複

這個測試不代表語意層面零重複：較短句子、相同概念的改寫、表格中的重疊描述，以及有意設計的蒸餾摘要都可能重疊。這類項目以 DUP-001～DUP-006 的責任矩陣判斷，而不是刪除來源。

## 8. 驗收界線

- Git Blob SHA 是 Git 物件識別碼，不等於裸檔 SHA-256 或 ZIP 成員 CRC32。
- 「檔案存在」「清單完整」「可以讀取」「可以解壓」「CRC 通過」「標題覆蓋」「表格相同」「正文語意等價」「實際執行通過」是不同驗收層級。
- 沒有完成某一層級的直接證據，就只標記該層級的狀態，不向上推論。
- 若提交後的實際 tree 與本報告預期數量不同，或發現新的重複 SHA／失效連結，應修正清冊與索引並重新驗收；不能保留不一致的結論。
