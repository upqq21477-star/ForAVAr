## 3. 封包 B 的內容蒸餾

企劃書自標示為 v0.1、PROPOSAL／尚待確認；不能當成 P2 已核准藍圖、Current 或實作證據。

### 3.1 核心流程

H0：解決問題。H1 五環節為：

**理解問題 → 決定做法 → 執行做法 → 檢查結果 → 修正與結案**

H0–H2 維持穩定；只有在能力選擇、條件判斷、策略分歧或回退位置需要分支時，才在 H3 展開。規劃、藍圖、施工、驗收及修正應共用流程原則，而不是各造一套生命週期。

### 3.2 單一權威底圖、多種視圖

樹狀位置表達「功能屬於哪裡」；前置條件、因果關係與封包引用表達「何時能做、結果交給誰、失敗回到哪裡」。功能樹、因果圖與角色圖若存在，應由同一份權威資料衍生，不能分別維護成多個真相來源。

### 3.3 最小封包契約

每個需持久化或交接的工作單位至少包含：

1. **定位與目標：** 封包 ID、所屬步驟、要解決的問題。
2. **輸入與條件：** 必要資料引用、前置狀態、權限及資源限制。
3. **動作與責任：** 允許執行的工作及負責角色／能力。
4. **結果與證據：** 產物、接受條件的核對結果、來源證據。
5. **狀態與下一步：** 當前狀態、下游或回退位置、阻塞／失敗原因。

### 3.4 中控最小責任

中控只負責：定位封包和合法下一步、檢查前置條件／權限／資源、派送已授權工作、接收結果和證據、依結果推進／回退／阻塞／停止。中控不取代語意決策、角色執行或獨立驗收。

### 3.5 狀態、啟用條件與證據

企劃書提出的初步狀態為 WAITING、READY、RUNNING、PASS、FAIL、BLOCKED。這是待與 P2 現有狀態機對帳的提案，不能直接新增成權威狀態。

能力啟用需同時檢查觸發、輸入、權限、資源、安全與衝突條件。可程式判定的硬條件由驗證器檢查；意圖與方法適用性屬語意判斷，必須保留來源、推論及假設。

狀態與證據分開：狀態說明工作走到哪；證據說明為何可相信結果。文件存在、靜態掃描、推論或模擬不能自動升格為真實執行通過。閉環後保留核心結果、決策、必要證據及下游所需資料，按規則封存或清理無用暫存。

## 4. Markdown／DOCX 差異結論

詳細數據、方法與限制見 參考資料/解析文檔/封包B雙格式完整性與差異稽核.md。

- 標題覆蓋：對話紀錄 75/75；企劃書 72/72，均可在對應 DOCX 主文件正文找到。
- 行級正向掃描：企劃書未完全匹配行的文字片段均可在 DOCX 正文找到；對話紀錄的多數未匹配項是清單／段落格式，另有歷史 sandbox 交付連結。
- DOCX 反向掃描：企劃書未發現低重疊的獨有正文段落；對話紀錄的低重疊候選為三個歷史 sandbox 下載路徑。
- 已確認的措辭差異：
  - Markdown：「這份紀錄涵蓋目前可見的本輪主題對話，共 13 則訊息……」
  - DOCX：「這份紀錄當時涵蓋本輪主題對話共 13 則訊息……」

**結論：** 未發現高可信度的實質章節缺失；兩組 Markdown／DOCX 的 13 張表已逐表、逐列、逐儲存格正規化比對，合計 137 列、379 個儲存格均無內容差異。格式間仍非逐字相同：對話紀錄 Markdown 的 5 個 sandbox 連結在 DOCX 中沒有可點擊的外部超連結，且範圍說明有措辭差異，故不能宣稱整份文件零遺漏或完全等價。對話紀錄也明確標示：主要訊息 1–15 的編號連續（8 則使用者、7 則助理），但訊息 1 之前有一則更早助理回覆僅保存結尾片段；因此它不是已證明完整的原始聊天匯出。

### 5.1 讀取阻塞與本輪重試（2026-10-20）

- GitHub Contents API 的 Base64 讀取對此大型二進位檔曾回傳空內容。
- Git Blob／一般 fetch 在嘗試將二進位內容當 UTF-8 文字時解碼失敗；直接查詢 Git Blob 的讀取工具亦回覆只接受 UTF-8 文字的 400 錯誤，沒有交付原始位元組。
- 先前執行環境直接下載曾遭 DNS 失敗。
- 本輪瀏覽器自動化以小寫 repository 路徑 `upqq21477-star/forAVAr` 嘗試讀取，收到 404；raw URL 逾時，未取回位元組。但正式 GitHub API tree 已確認檔案位於 canonical repository `upqq21477-star/ForAVAr`，大小為 1,885,519 bytes、Git Blob SHA 為 `0e58526bd35c30a25f3b27033a4952ec5f25bf10`。因此此次瀏覽器 404 與檔案樹證據矛盾，只能算取得路徑／傳輸失敗，不能認定檔案不存在。
- 沒有從上述重試取得 ZIP 位元組；成員清單、CRC、壓縮方法及內容仍未知。

**狀態：BLOCKED，不是檔案損壞，也不是檔案不存在。** 在取得可解析位元組之前，不對 ZIP 內部程式、工具、測試、版本或完整性作內容判定。
