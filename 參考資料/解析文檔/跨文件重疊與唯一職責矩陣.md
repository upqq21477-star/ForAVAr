<a id="current-rules"></a>
## 1. 目前權責原則

- README 是唯一全域入口；[文件與分支索引](../文件與分支索引.md)維護現行主軸清單。
- MASTER 只保存共同結論、TOC、分支索引和未決事項；詳細證據只放入唯一責任分支。
- 原始來源不改寫；研究分析、蒸餾摘要、問題追蹤與架構提案不得互相取代。
- 相似文字不等於重複：依唯一責任、來源版本、證據與可支持的結論判定。
- 舊的按日期追加章節保留在歷史分支，供回查當時的歸位裁定；現行權威狀態以對應 MASTER／權威文件為準。
- 新增／移動／分流／取代／刪除任何文件前，先查入鏈、出鏈及引用影響；所有更新在讀回驗收後才可輪替備份。
