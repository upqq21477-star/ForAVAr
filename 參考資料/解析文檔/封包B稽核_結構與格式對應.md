### 3.1 初步正規化指標

### 3.2 逐行初篩

| 配對 | 有效 Markdown 行 | 完全匹配行 | 未完全匹配行 | 低重疊候選 |

企劃書 50 個未完全匹配行的文字片段均能在 DOCX 主文件正文找到；差異主要涉及清單編號、Word 編號屬性及段落邊界。對話紀錄大部分未完全匹配行亦能找到相應文字片段。這支持「初篩未發現高可信度的實質章節缺失」，但不等於所有非表格內容均已逐句作語意裁定。

### 3.3 已確認的範圍說明差異

- Markdown：「這份紀錄涵蓋目前可見的本輪主題對話，共 13 則訊息……」
- DOCX：「這份紀錄當時涵蓋本輪主題對話共 13 則訊息……」

兩句的範圍措辭略有不同。文件前段明確將訊息 1–13 定義為核心設計討論及文件整理要求，訊息 14–15 定義為文件交付後的保存位置與完整性檢查；「共 13 則」因此可能只指核心主題訊息。現有來源不足以證明這是數字錯誤，改按範圍措辭歧義追蹤，保留原文而不自行更正。

- 對話紀錄 Markdown 的 5 個歷史 sandbox URL 文字均出現在 DOCX 主文件中；但 DOCX 有 0 個 w:hyperlink 元素與 0 個外部關係，故保留了網址文字，未保留可點擊的連結行為。這些歷史 sandbox 路徑不應直接當成目前可用的 GitHub 下載連結。
