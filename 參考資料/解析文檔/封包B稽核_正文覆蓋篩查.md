## 9. 非表格正文第二輪覆蓋篩查（2026-10-20）

### 9.1 方法

對 Markdown 移除表格列及 Markdown 呈現標記；對 DOCX 從 `word/document.xml` 排除 `w:tbl` 表格區塊後抽取正文段落。文字統一使用 NFKC，去除空白、標點、符號及零寬字元，再比對唯一六字元連續片段（6-gram）集合、雙向覆蓋率與行／段落級低覆蓋候選。這是可重現的文字覆蓋篩查，不是語意模型判斷，也不將覆蓋率當成內容完整百分比。

### 9.4 主文件以外部件

兩份 DOCX 均有 Word 頁首與頁尾，文字分別是文件名／「討論整理稿」及「討論稿」識別；註腳與註解 XML 文字為空。這些屬 Word 版面識別元資料，沒有與 Markdown 正文一一對應的內容。所有相關部件及關係目標已通過結構檢查。

### 9.5 判定與保留限制

- 第二輪篩查的共通片段覆蓋率均高於 98.5%；標題覆蓋與 379 個表格儲存格已另行通過；沒有發現高可信度的實質缺章候選。
- 已識別的差異主要是交付連結的可點擊功能／顯示方式及 Word 標題編號表示法；對話紀錄中的 13／15 則訊息範圍措辭與訊息 1 前回覆缺口需保留，不應由跨格式比對靜默修正。
- **本節不宣告 Markdown 與 DOCX 原始字元逐字相同。** 第 9.6 節完成有序差異逐項分類；在本報告界定的正文抽取、正規化與表格檢查範圍內，沒有未解釋的實質內容缺失。


### 9.6 非表格正文有序字元序列差異（最終裁定）

#### 方法

排除 Markdown 表格列及 DOCX 的 OOXML 表格區塊，移除 Markdown 呈現標記；正文統一為 NFKC、小寫，去除空白、標點、符號與零寬字元，再做有序字元序列差異比對。表格已獨立以 379 個儲存格逐格比對。這是明確範圍內的內容對照，不是對原始檔位元組或格式層的逐字元等價宣稱。

#### 結果

| 配對 | Markdown 字元 | DOCX 字元 | 共同有序字元 | Markdown 未匹配字元 | DOCX 額外字元 | 共同字元／DOCX |
|---|---:|---:|---:|---:|---:|---:|
| 對話原文紀錄 | 10,502 | 10,642 | 10,463 | 39 | 179 | 98.32% |
| 企劃書 v0.1 | 9,887 | 9,923 | 9,887 | 0 | 36 | 99.64% |

#### 差異分類與裁定

1. **Word 編號：** DOCX 額外的數字字元對應章節標題與層級編號。Markdown 標題覆蓋 75/75、72/72，未發現缺章。
2. **交付連結：** 對話紀錄五個 sandbox URL 文字在 DOCX 主文都能找到，但沒有可點擊 hyperlink／外部關係；Word 顯示的短標籤有少量說明詞被縮短。此為連結行為與顯示標籤的格式損失，不是五個目標文字全部消失。
3. **範圍措辭：** 「目前可見的」與「當時」有少量措辭差異。文件前段把 1–13 定義為核心主題，把 14–15 定義為交付後續，所以 13／15 依目前證據屬範圍措辭歧義，不視為已證實數字錯誤。
4. **表格引導句：** Markdown 在表格前有「企劃書已整理以下內容」的引導句；DOCX 直接呈現相同表格及後續說明。13 張表、137 列、379 格逐格文字一致，未出現表格資料缺失。
5. **內部目錄連結：** 企劃書 DOCX 的 20 個 TOC anchor 全部對應到存在的 bookmark，缺失 0。
6. **主文件外部件：** 兩份文件的註腳／註解 XML 沒有文字；頁首／頁尾內容是標題與稿件識別，不是與 Markdown 正文一一對應的內容。

**GAP-002 判定：RESOLVED_WITH_LIMITATIONS。** 在本報告界定的抽取與正規化範圍內，所有有序字元差異均已分類，沒有未解釋的實質內容缺失。這不代表 Markdown 與 DOCX 原始字元逐字相同；訊息 1 前的前置助理回覆缺口仍獨立由 GAP-001 保留，五個 sandbox 連結的可點擊功能損失仍由 FMT-001 保留。
