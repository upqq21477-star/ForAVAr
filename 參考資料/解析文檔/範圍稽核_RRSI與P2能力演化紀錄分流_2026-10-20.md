## 5. 發生原因分析

### 5.1 已有證據支持的問題

1. **本輪任務與新增文件的主題不一致。** 新增文件聚焦 P2 市場／名稱、P2 原始願景與能力演化框架；這些不是 RRSI 原始研究紀錄的主責。
2. **多輪對談範圍缺少可追溯的逐輪來源映射。** P2 文件以 R1–R4 組織內容，但正文未提供每輪對談的精確來源連結、訊息識別或逐條對應證據，無法僅靠文件確認四輪界線的正確性。
3. **索引和職責登錄只驗證了文件進入資訊架構。** 它們沒有證明文件是否符合當前主題；文件可被正確登錄，但仍可能是當前任務的錯誤交付。
4. **最新提交只修訂 P2 文件。** 提交 `95f8890` 修改的是 P2 研究文件，並非 RRSI 文件；因此不能把該提交描述成 RRSI 內容更新。

### 5.2 依文件內容作出的原因推論

以下是根據內容相似度及提交順序作出的推論，不是 Git 記錄直接證明的模型內部因果：

- **相近概念造成語意串題。** RRSI 與 P2 能力演化都涉及自我改進、演化、治理、驗證和回退；若只用這些共同詞彙判斷相關性，容易把特定研究與更廣泛的架構討論混為同一任務。
- **跨對談整合時，舊主題素材被重新帶入。** P2 文件把市場／名稱分析和原始設計動機放在 R1、R2，顯示整合範圍以先前的 P2 討論為主，而不是以當前 RRSI 研究為主。
- **缺少寫入前的主題一致性閘門。** 流程在完成正文後就更新索引和職責矩陣，沒有先回答「這份文件是否真是本次指定主題的交付物」。這解釋了偏移為何不只出現在正文，也進入了索引與矩陣。

### 5.3 目前無法確定的事項

P2 文件聲稱，使用者明確要求把先前曾標示為「不列入紀錄」的市場／名稱分析納入整合。GitHub 提交只能證明文件中存在這項敘述，不能證明原始對談中確實有相應授權。由於目前沒有完成該段原始對談逐字來源的核驗，本稽核不把這項授權聲稱判定為真或假。
